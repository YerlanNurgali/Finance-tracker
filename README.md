# 💰 Finance Tracker

Простой консольный трекер личных финансов на Python.

Проект позволяет добавлять доходы и расходы, хранить историю операций, редактировать и удалять операции, просматривать статистику и расходы по категориям.

## 🚀 Возможности

- Добавление доходов
- Добавление расходов
- Проверка достаточности средств
- Категории расходов
- Просмотр текущего баланса
- История операций
- Статистика доходов и расходов
- Расходы по категориям
- Текстовая диаграмма расходов
- Редактирование операций
- Удаление операций
- Сохранение данных в файл
- Автоматические тесты с pytest

## ⚙️ Установка

Клонировать репозиторий:

```bash
git clone https://github.com/YerlanNurgali/Finance-tracker.git
cd Finance-tracker
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## ▶️ Запуск

Запустить приложение:

```bash
python main.py
```

После запуска появится меню:

```text
1. Добавить доход
2. Добавить расход
3. Показать баланс
4. Показать историю
5. Показать статистику
6. Показать диаграмму
7. Удалить операцию
8. Редактировать операцию
9. Выход
```

## 🧪 Тестирование

Запустить автоматические тесты:

```bash
python -m pytest
```

Текущий результат:

```text

```
