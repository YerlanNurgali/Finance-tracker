# 💰 Finance Tracker

Трекер личных финансов на Python: консольное меню и веб-приложение на FastAPI.

Проект позволяет добавлять доходы и расходы, хранить историю операций, редактировать и удалять операции, просматривать статистику и расходы по категориям.

Данные хранятся в Neon PostgreSQL (подключение через `DATABASE_URL`).

## 🚀 Возможности

- Добавление доходов
- Добавление расходов
- Проверка достаточности средств
- Категории доходов и расходов
- Просмотр текущего баланса
- История операций
- Статистика доходов и расходов
- Расходы по категориям
- Текстовая диаграмма расходов
- Редактирование операций
- Удаление операций
- Веб-интерфейс (FastAPI)
- Автоматические тесты с pytest

## ⚙️ Установка

Клонировать репозиторий:

```bash
git clone https://github.com/YerlanNurgali/Finance-tracker.git
cd Finance-tracker
```

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env` в корне проекта и указать строку подключения к Neon:

```bash
DATABASE_URL=postgresql://user:password@host/dbname?sslmode=require
```

Подставьте свой URL из панели Neon. Файл `.env` не коммитится в Git.

## ▶️ Запуск

Веб-приложение (FastAPI / Uvicorn):

```bash
uvicorn api:app --reload
```

После запуска откройте в браузере адрес, который покажет Uvicorn (обычно `http://127.0.0.1:8000`).

Консольное меню:

```bash
python main.py
```

```text
1. Добавить доход

3. Показать баланс
4. Показать историю
```

## 🧪 Тестирование

Запустить автоматические тесты:

```bash
python -m pytest
```

Для тестов также нужен рабочий `DATABASE_URL` в `.env`.
